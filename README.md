# fantan-app
本app提供6種策略讀供押注，並有模擬苛官及策略診斷以供時時更改策略。

「Fan Tan 番攤」是在澳⾨較⼤型賭場可找到的賭戲。賭戲採⽤⼀堆⽩⾊ 鈕扣、⼀只碗、⼀根⼩撥棒⼦。賭戲所玩的桌⼦⼤約和花旗骰Craps賭桌 那般⼤⼩, 荷官站在中間的位置, ⾝旁有⼀個透明圓罩蓋住⼀堆鈕扣。賭桌 前⾯兩側是下注的地⽅, 可容納約六名玩家舒服地參與押注。賭桌上押注 的部分為塑料製成。當結果出來之後, 所有的贏注部分會被標註出來, 就像 Sic Bo骰寶賭戲那般。

遊戲開始, 荷官將那只碗蓋在那⼀堆鈕扣上⾯, 依我的經驗, 每次那只碗平 均約蓋住60顆鈕扣左右。接著玩家們開始在各式各樣的押注地⽅下注。下 ⼀步, 荷官將碗移到中間、掀開蓋住的碗、⽤棒⼦將碗底下的鈕扣每四顆 ⼀撥、⼀撥⼀撥將鈕扣分開。最後剩下的那⼀撥的鈕扣數⺫即是下注贏⾯ 的依據, 數⺫從⼀顆到四顆鈕扣。押注也是從⼀到四、其中押中者贏得同 等⾦額的賭注、並根據贏得的賭⾦抽取少於5%的佣⾦。在push平⼿狀況 下不抽取佣⾦。以下列表顯⽰贏局的⽀付、基於押注⾦額的「⼀倍」為計 算基準、並扣除5%佣⾦之後的調整賠率。

以下是可以押注的⽅式。我是從澳⾨威尼斯⼈Venetian Macau的規則⼿冊 得知這些名詞的。

番: 對單⼀號碼押注。贏者得以⽀付3⽐1的賠率(抽佣前), 或2.85倍的賠 率(抽佣後)。賭場優勢為3.75%.
念: 押注兩個號碼, 其中⼀個被標⽰為平⼿。贏者得以⽀付2⽐1的賠率(抽 佣前), 或1.9倍的賠率(抽佣後)。賭場優勢為2.50%
⾓: 押注兩個號碼, 開出為贏。贏者得以⽀付1⽐1的賠率(抽佣前), 或 19/20倍的賠率(抽佣後)。賭場優勢為2.50%.
丫攤: 押注三個號碼, , 其中⼀個被標⽰為平⼿。贏者得以⽀付1/2的賠率 (抽佣前), 或19/40倍的賠率(抽佣後)。賭場優勢為1.25%.
三⾨: 押注三個號碼, 開出為贏。贏者得以⽀付1/3的賠率(抽佣前), 或 19/60倍的賠率(抽佣後)。賭場優勢為1.25%.
